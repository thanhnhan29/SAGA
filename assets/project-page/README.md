# SAGA: Stable Acceleration Guidance for Autoregressive Video Generation

Official project page and visual demonstration code for **SAGA: Stable Acceleration Guidance for Autoregressive Video Generation** (Accepted at **ACCV 2026**, Paper ID 452).

## Authors
- **Thanh-Nhan Vo** (VNU-HCM University of Science)
- **Trong-Thuan Nguyen** (VNU-HCM University of Science)
- **Trung-Hoang Le** (VNU-HCM University of Science)
- **Tam V. Nguyen** (University of Dayton)
- **Minh-Triet Tran** (VNU-HCM University of Science)

## Overview
This repository contains the interactive research project page demonstrating:
- Synchronized side-by-side & split-screen video comparisons between baseline autoregressive backbones and SAGA.
- Quantitative benchmark results on the VBench suite and human preference evaluation.
- Diverse aesthetic showcases across artistic, sci-fi, nature, and conceptual prompts.

## Running Locally
To view the project page locally, start any static HTTP server from this directory:
```bash
python3 -m http.server 8765
```
Then open `http://localhost:8765` in your browser.
